# Handoffs

Create one concise record for meaningful completed or interrupted work.

Filename format:

```text
YYYY-MM-DD-HHMM-short-task-name.md
```

Use `templates/handoff-entry.md`. A handoff records outcomes, verification, blockers, and the next action; it does not duplicate entire chat transcripts or large diffs.

Keep `STATE.md` as the current snapshot and use this folder for history.
